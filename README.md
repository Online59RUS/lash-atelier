# LASH ATELIER — сайт Валерии

Готовый сайт для GitHub Pages. React, Node.js, npm и сборка не нужны.

## Какие файлы за что отвечают

- `index.html` — весь текст, услуги, цены, адрес, телефон и имя мастера.
- `styles.css` — цвета, расположение блоков, фотографии и мобильная версия.
- `script.js` — выбор услуги, времени и форма записи.
- `images/lash-hero.png` — главная фотография.
- `images/lash-detail.png` — крупный план ресниц.
- `images/og.png` — обложка для публикации ссылки.

## Как добавить скачанные фотографии

Положи фотографии в папку `images` и назови их так:

- `wet-look.jpg` — фотография для блока «Мокрый эффект».
- `foxy.jpg` — фотография для блока «Лисий взгляд».
- `geometry.jpg` — фотография для блока «Своя геометрия».
- `valeria.jpg` — фотография мастера.

Пока этих файлов нет, сайт автоматически показывает прежние фотографии из Unsplash.

Если скачанные фотографии имеют расширение `.png`, переименуй путь в `styles.css`
или сохрани изображения в формате `.jpg`.

## Как открыть сайт

Просто открой `index.html` в браузере. Для удобного просмотра из VS Code можно
установить расширение Live Server и выбрать «Open with Live Server».

## Как опубликовать на GitHub Pages

1. Создай на GitHub новый публичный репозиторий, например `lash-atelier`.
2. Загрузи содержимое этой папки в корень репозитория.
3. Открой репозиторий → Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main`, папку `/ (root)` и нажми Save.
6. Через несколько минут сайт откроется по адресу:
   `https://ТВОЙ-ЛОГИН.github.io/lash-atelier/`.

Важно: `index.html` должен лежать в корне репозитория, а не внутри лишней папки.

## Как включить настоящую запись

Открой `script.js` и замени:

```js
const WHATSAPP_NUMBER = "";
```

на реальный номер Валерии без плюса, пробелов и скобок:

```js
const WHATSAPP_NUMBER = "79001234567";
```

Тогда после заполнения формы откроется WhatsApp с готовым сообщением.
Отдельный сервер для этого не нужен.

Обязательно замени тестовые адрес, телефон, стоимость услуг и фотографию мастера
на настоящие данные заказчицы.
